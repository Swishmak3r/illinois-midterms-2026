# Self-hosted typefaces

Downloaded October 27, 2026 from the official Google Fonts CSS API and fonts.gstatic.com.

| File | Family | Style | Weight range | Subset | Bytes |
| --- | --- | --- | --- | --- | --- |
| dm-sans-latin-wght.woff2 | DM Sans | normal | 400–700 | Latin | 36,932 |
| fraunces-latin-normal.woff2 | Fraunces | normal | 400–600 | Latin | 36,864 |
| fraunces-latin-italic.woff2 | Fraunces | italic | 400–600 | Latin | 45,336 |

Total WOFF2 payload: **119,132 bytes**. Fraunces uses a fixed display optical size of 72 and variable weight. DM Sans uses variable weight. Load with `font-display: swap`; use system fallbacks for characters outside the Latin subset.

Official request:

https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Fraunces:ital,opsz,wght@0,72,400..600;1,72,400..600&display=swap

The returned stylesheet is retained as `google-fonts-source.css` for provenance, not runtime loading. The website serves the WOFF2 files locally.
