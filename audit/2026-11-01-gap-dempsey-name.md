# Dempsey name discrepancy — identity cross-check

Checked November 1, 2026. Research only; no candidate data changed.

## Finding

The court's current official name is **Maire Dempsey**, with the full form **Maire Aileen Dempsey** documented in an official assignment order. The current election data uses **Marie Aileen Dempsey**. This is a real source spelling discrepancy, rather than an unsupported bar-association name match.

Recommended handling: retain **Marie Aileen Dempsey** as the current election/ballot display name and preserve the existing candidate ID. Add **Maire Aileen Dempsey** as the court/evaluation source name and a matching alias. Display a brief note when presenting her biography or bar evaluations: **“Election listings use Marie Aileen Dempsey; the court and bar evaluations use Maire Aileen Dempsey.”** Both spellings should find the same candidate.

Do not silently replace the election name or say an election authority has acknowledged or corrected a typo. The evidence strongly supports a transposed-letter spelling error, but its origin and any formal correction have not been established. No primary source explaining a legal name change or intentional alias was found in the bounded search.
