# Current legislative incumbency — November 1, 2026

The accompanying JSON contains all 118 current House members and 59 current Senate members from the Illinois General Assembly's current 104th General Assembly rosters. It records only public-office identity, chamber, district, party and official source URL; contact and residence data were omitted.

## Access and verification

Direct HTTP requests to the current ILGA table and card pages returned HTTP 403. Search-indexed versions of the official pages were readable. Records were extracted from those official indexed pages, deduplicated by chamber and district, and checked for all 118 House and 59 Senate districts. Former-member sections were excluded. This is indexed-source evidence, not a claim of live page access.

Official sources:

- [House table](https://www.ilga.gov/House/Members/List)
- [House table on the official my.ilga.gov host](https://my.ilga.gov/House/Members/List)
- [House member cards](https://www.ilga.gov/house/members/)
- [Senate table](https://www.ilga.gov/Senate/Members/List)

The JSON's per-record URL identifies which indexed official page supplied the retained record. Individual member detail URLs were not fabricated or inferred. The source check does not establish legislative candidate ballot qualification; compare separately with the SBE general-election snapshot.
